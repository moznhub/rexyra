## Several clients on the same prefix, and on overlapping prefixes
p1: HELLO 3 @@ proto id
p1: CLIENT TRACKING ON BCAST PREFIX user:
p2: HELLO 3 @@ proto id
p2: CLIENT TRACKING ON BCAST PREFIX user: PREFIX order:
p3: HELLO 3 @@ proto id
p3: CLIENT TRACKING ON BCAST PREFIX user:1
w: INFO stats @@ tracking_total_prefixes
w| SET user:2 x ;; SET user:10 x ;; SET order:1 x ;; SET other x
~drain
p2: CLIENT TRACKING OFF
w: INFO stats @@ tracking_total_prefixes
w: SET order:2 x
w: SET user:11 x
~drain
